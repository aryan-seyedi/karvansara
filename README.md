# Karvansara.org (کاروانسرا)

Digital library and cultural hub for the "Silk Road neighborhood" (Iran, Tajikistan, Afghanistan, Kurdistan, Turkmenistan, Kazakhstan, Uzbekistan, and Kyrgyzstan).

## 🚀 Tech Stack
- **Frontend:** Next.js (Vercel)
- **Database:** Supabase (PostgreSQL)
- **Data Source:** Information available on the world wide web

## 📂 Project Structure
- `/supabase/migrations`: Database schema and migrations.
- `/scripts`: Python/Node.js scripts for scraping and data sync.
- `/app`: Next.js frontend code.

## 🏛️ Linguistic Characteristics
- Parsi (Old Persian/Avestan), Turkic, Arabic influence in terminology.
- Transliteration: "Karvansara" (no double 'a').

## 🏺 Symbolism
- **Anar (Pomegranate):** Fertility, life, and shared heritage across the Silk Road.
